🎨 قالب ۴: تکسچر و متریال

📖 مقدمه

تکسچرها تصاویری هستند که روی سطوح اشیاء قرار می‌گیرند. در این درس با انواع تکسچر و متریال‌های پیشرفته آشنا می‌شویم.

🎨 انواع متریال

  • MeshBasicMaterial: بدون واکنش به نور
  • MeshStandardMaterial: PBR استاندارد
  • MeshPhysicalMaterial: PBR پیشرفته (شیشه)
  • MeshPhongMaterial: براق
  • MeshLambertMaterial: مات

📷 بارگذاری تکسچر

const loader = new THREE.TextureLoader(); const texture = loader.load('texture.jpg'); const material = new THREE.MeshStandardMaterial({ map: texture });

🖼️ تکسچر با Canvas

const canvas = document.createElement('canvas'); canvas.width = 256; canvas.height = 256; const ctx = canvas.getContext('2d'); // رسم الگو ctx.fillStyle = '#ff6b6b'; ctx.fillRect(0, 0, 256, 256); const texture = new THREE.CanvasTexture(canvas);

✨ متریال متالیک

const material = new THREE.MeshStandardMaterial({ color: 0xff6b6b, metalness: 0.9, // خیلی فلزی roughness: 0.1 // خیلی صاف });

🔮 متریال شیشه‌ای

const glassMaterial = new THREE.MeshPhysicalMaterial({ color: 0x88ccff, metalness: 0, roughness: 0, transmission: 0.9, // شفافیت thickness: 0.5 // ضخامت });

🔁 تکرار تکسچر

texture.wrapS = THREE.RepeatWrapping; texture.wrapT = THREE.RepeatWrapping; texture.repeat.set(4, 4); // ۴ بار تکرار

💡 نکته

🎓 MeshPhysicalMaterial سنگین‌تر از MeshStandardMaterial است. فقط زمانی از آن استفاده کنید که به transmission (شیشه) نیاز دارید!
