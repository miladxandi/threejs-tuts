🎮 قالب ۳: کنترل دوربین با OrbitControls 🖱️ چپ‌کلیک: چرخش | راست‌کلیک: جابجایی | اسکرول: زوم

📖 مقدمه

OrbitControls یک ابزار قدرتمند برای کنترل دوربین است که به کاربر اجازه می‌دهد صحنه را از زوایای مختلف ببیند.

🎮 قابلیت‌ها

  • چرخش: کلیک چپ + درگ
  • جابجایی: کلیک راست + درگ
  • زوم: اسکرول ماوس
  • لمسی: پشتیبانی از تاچ

📦 بارگذاری

OrbitControls جدا از Three.js اصلی است:

<!-- بعد از Three.js --> <script src="three/examples/js/controls/OrbitControls.js"></script>

⚙️ راه‌اندازی

const controls = new THREE.OrbitControls( camera, // دوربین renderer.domElement // المان رندرر ); // حرکت نرم controls.enableDamping = true; controls.dampingFactor = 0.05; // چرخش خودکار controls.autoRotate = true; controls.autoRotateSpeed = 1;

🔧 تنظیمات

// محدود کردن زوم controls.minDistance = 2; controls.maxDistance = 50; // محدود کردن زاویه عمودی controls.minPolarAngle = 0; // بالا controls.maxPolarAngle = Math.PI / 2; // افق // غیرفعال کردن قابلیت‌ها controls.enablePan = false; controls.enableZoom = false;

🔄 آپدیت

برای Damping باید در حلقه انیمیشن آپدیت شود:

function animate() { requestAnimationFrame(animate); // مهم! برای حرکت نرم controls.update(); renderer.render(scene, camera); }

🏗️ GridHelper

const gridHelper = new THREE.GridHelper( 20, // اندازه 20, // تعداد تقسیمات 0x00ced1, // رنگ مرکز 0x1a3a4a // رنگ شبکه ); scene.add(gridHelper);

💡 نکته

🎓 OrbitControls برای نمایش محصولات 3D، ویوئرهای مدل و بازی‌های سه‌بعدی عالی است. همیشه enableDamping را فعال کنید تا حرکت نرم‌تر شود!
