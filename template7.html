🎬 قالب ۷: انیمیشن حرفه‌ای با GSAP

📖 مقدمه

GSAP (GreenSock Animation Platform) قدرتمندترین کتابخانه انیمیشن جاوااسکریپت است. با Three.js ترکیب عالی دارد!

📦 بارگذاری

<script src="gsap.min.js"></script>

🎯 انیمیشن ساده

gsap.to(mesh.position, { y: 2, // مقدار نهایی duration: 0.5, // مدت زمان ease: "power2.out" // نوع easing });

🔄 Yoyo و Repeat

gsap.to(mesh.scale, { x: 1.5, y: 1.5, z: 1.5, duration: 0.5, yoyo: true, // برگشت repeat: 1 // یکبار تکرار (رفت و برگشت) });

⏱️ Timeline

برای انیمیشن‌های پشت سر هم:

const tl = gsap.timeline(); tl.to(obj.position, { y: 2, duration: 0.3 }) .to(obj.rotation, { y: Math.PI, duration: 0.5 }) .to(obj.position, { y: 0, duration: 0.3 });

🎨 انواع Easing

  • power1-4: ease.out, ease.in, ease.inOut
  • bounce: پرش توپی
  • elastic: کش‌دار
  • back: عقب رفتن قبل از حرکت
ease: "bounce.out" ease: "elastic.out(1, 0.3)" ease: "back.inOut(1.7)"

⏰ Delay

gsap.to(mesh.position, { y: 2, duration: 0.5, delay: 0.5 // نیم ثانیه تاخیر });

💡 نکته

🎓 دکمه‌های پایین صفحه را امتحان کنید! "همه با هم" از Timeline استفاده می‌کند و نشان می‌دهد چطور انیمیشن‌ها را زنجیره کنید.
