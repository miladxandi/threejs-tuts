🎲 قالب ۱: مکعب چرخان - سطح مبتدی

📖 مقدمه

به اولین درس Three.js خوش آمدید! در این درس با مفاهیم پایه‌ای آشنا می‌شویم که برای هر پروژه سه‌بعدی نیاز است.

🎯 مفاهیم کلیدی

  • Scene: صحنه‌ای که همه اشیاء در آن قرار می‌گیرند
  • Camera: دوربینی که صحنه را می‌بیند
  • Renderer: موتور رندر که تصویر را نمایش می‌دهد
  • Geometry: شکل هندسی (مثل مکعب)
  • Material: ظاهر و رنگ شیء
  • Mesh: ترکیب Geometry + Material

💻 ایجاد صحنه

اولین قدم ایجاد یک صحنه است:

const scene = new THREE.Scene(); scene.background = new THREE.Color(0x0a0a1a);

📷 تنظیم دوربین

دوربین پرسپکتیو برای دید سه‌بعدی واقعی:

const camera = new THREE.PerspectiveCamera( 75, // زاویه دید (FOV) width / height, // نسبت تصویر 0.1, // نزدیک‌ترین 1000 // دورترین ); camera.position.z = 5;

🖥️ ایجاد Renderer

const renderer = new THREE.WebGLRenderer({ antialias: true }); renderer.setSize(window.innerWidth, window.innerHeight); document.body.appendChild(renderer.domElement);

📦 ایجاد مکعب

// هندسه مکعب (عرض، ارتفاع، عمق) const geometry = new THREE.BoxGeometry(2, 2, 2); // متریال نرمال (رنگ بر اساس جهت سطح) const material = new THREE.MeshNormalMaterial(); // ترکیب هندسه و متریال const cube = new THREE.Mesh(geometry, material); scene.add(cube);

🔄 حلقه انیمیشن

برای ایجاد حرکت، یک حلقه تکرار شونده نیاز است:

function animate() { requestAnimationFrame(animate); // چرخش مکعب cube.rotation.x += 0.01; cube.rotation.y += 0.01; renderer.render(scene, camera); } animate();

💡 نکته مهم

🎓 MeshNormalMaterial یک متریال خاص است که رنگ هر سطح را بر اساس جهت نرمال آن تعیین می‌کند. برای دیباگ و تست بسیار مفید است!
