💎 قالب ۲: اشکال هندسی + نورپردازی

📖 مقدمه

در این درس با انواع اشکال هندسی و سیستم نورپردازی Three.js آشنا می‌شویم. نور برای دیدن اشکال با متریال‌های استاندارد ضروری است.

💡 انواع نور

  • AmbientLight: نور محیطی یکنواخت
  • PointLight: نور نقطه‌ای (مثل لامپ)
  • DirectionalLight: نور جهت‌دار (مثل خورشید)
  • SpotLight: نور اسپات (مثل چراغ قوه)

🌟 نور محیطی

// نور محیطی - همه جا یکسان const ambientLight = new THREE.AmbientLight( 0x404040, // رنگ 0.5 // شدت ); scene.add(ambientLight);

💫 نور نقطه‌ای

const pointLight = new THREE.PointLight( 0xff6b6b, // رنگ قرمز 1, // شدت 100 // برد ); pointLight.position.set(5, 5, 5); pointLight.castShadow = true; scene.add(pointLight);

📐 اشکال هندسی

// کره new THREE.SphereGeometry(1, 32, 32); // دونات (Torus) new THREE.TorusGeometry(0.8, 0.3, 16, 100); // مخروط new THREE.ConeGeometry(1, 2, 32); // استوانه new THREE.CylinderGeometry(1, 1, 2, 32);

🎨 MeshStandardMaterial

متریال استاندارد که به نور واکنش نشان می‌دهد:

const material = new THREE.MeshStandardMaterial({ color: 0xff6b6b, metalness: 0.3, // میزان فلزی بودن roughness: 0.4 // زبری سطح });

🌑 سایه

// فعال‌سازی سایه در Renderer renderer.shadowMap.enabled = true; // اشیاء سایه بیاندازند mesh.castShadow = true; // زمین سایه دریافت کند plane.receiveShadow = true;

💡 نکته

🎓 برای دیدن متریال‌های Standard و Physical حتماً به نور نیاز دارید! بدون نور این متریال‌ها کاملاً سیاه دیده می‌شوند.
